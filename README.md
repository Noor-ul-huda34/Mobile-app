# Mobile App Blog Website

A responsive blogging website built using **HTML, CSS, Bootstrap 5**, and modern web design principles.

## 📖 Overview

Mobile App Blog is a simple and responsive website that provides informative blog posts about web development technologies. The website includes a modern navigation bar, hero section, blog cards with images, and a footer.

## ✨ Features

* Responsive Navigation Bar
* Hero Section
* Blog Cards with Images
* Hover Effects on Cards
* Search Bar
* Sign In & Login Buttons
* Mobile-Friendly Design
* Bootstrap 5 Integration
* Clean and Modern UI

## 🛠 Technologies Used

* HTML5
* CSS3
* Bootstrap 5.3.8
* JavaScript (Bootstrap Bundle)
